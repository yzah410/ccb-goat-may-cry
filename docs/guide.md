# 使用说明

## 各个页面

| 页面 | 做什么 |
|---|---|
| 工作台 | 用「范围 + 条件」圈题库，看人数，抽一题。可以一句话让 AI 填条件 |
| 候选池 | 看工作台圈到的全部角色（卡片 / 列表 / 统计），每个角色按游戏规则显示作品标签；可以挑一个设为当前题目 |
| 方案库 | 工作台保存过的方案 |
| 清单 | 角色、作品、标签清单。例如建一份「已经背熟的角色」，在方案里排除它们 |
| 导图导出 | 看导图、管理导图方案库，把题库导出成 Obsidian 的 `.canvas` 文件 |
| 问数据 | 一句话问数据库，AI 写查询；结果能存成清单或工作台条件 |
| 单人猜猜呗 | 用工作台或保存的方案出题，在出题器里直接猜 |
| 数据 | 数据库的数据量、版本、构建时间 |
| 主题 | 切换主题，或分屏对比两套主题 |
| 设置 | 后端地址、显示、标签分档、AI、缓存、外观 |

经典工作台和自动点击是早期版本留下来的，见 [legacy.md](legacy.md)。

## 安装细节

- **Python**：3.10 或更高。Debian / Ubuntu 要先装 `python3-venv`（`sudo apt install python3-venv`）。
- **Node.js**：20.19 及以上的 20.x、22.13 及以上的 22.x，或 24 及更新版本（和 `web/package.json` 的 `engines` 一致；21.x、23.x 和更老的版本不行）。
- **装依赖的脚本**做两件事：在 `backend/venv` 建 Python 虚拟环境并装后端依赖；在 `web/` 里用 `npm ci` 装前端依赖。哪一步失败就停在那一步并说明原因，处理后重新运行即可。
- **数据库放在别处**：第一次启动后会生成 `backend/config.json`，把里面的 `v2.db_path` 改成数据库的路径。相对路径按仓库根目录算。
- **`search_aliases.sqlite`** 是可选的：单人猜猜呗按别名搜角色时用。要和 `outsetter_v2.sqlite` 放在同一个文件夹。

## 公式角色和标签分档

「公式角色」是每局开头先猜的 2–3 个角色。第一次打开时选一组，出题器按它们的标签把常用标签分档；角色卡片的标签分栏和导图都按这个分档显示。以后可以在「设置 → 标签分档」里改。

## 样例导图

仓库在 `examples/maps/` 里带了 306 张样例导图。它们在「导图导出」页的「方案库」标签里按年份分组列出，可以打开、改名、删除。

- **默认显示的几张**：第一次启动后端时，如果导图方案库是空的，会把 `examples/maps/defaults.txt` 里列的 6 张复制进 `data/maps_v2/`。这一步只做一次，之后删掉的样例不会自己回来。
- **载入全部**：方案库里有「载入全部样例导图（还有 N 张）」按钮。点一下，把还没有的样例都复制进来；已经有的跳过，不会覆盖你改过的内容。删掉的样例想要回来，也点这个按钮。
- **标签分组**：每张样例导图存着自己的标签分组。在「设置 → 标签分档」里改分档，不会改动样例的分组。

## 数据更新

数据库会定期更新。下载新的 `ccb-goat-may-cry-data-<日期>.zip`，替换 `data/` 里的两个 `.sqlite` 文件，再重启后端。你保存的方案、清单、分档存在 `data/` 的其他文件里，不受影响。

## 换端口

默认前端在 5175，后端在 8099。要换的话，在 `web/.env.development.local` 里写：

```
WEB_PORT=5175
VITE_API_BASE=http://127.0.0.1:8099
```

启动脚本会读这两项：用 `VITE_API_BASE` 里的端口启动后端，按 `WEB_PORT` 打开页面。也可以在「设置 → 后端地址」临时切换。

## 壁纸

壁纸要自己放进 `assets/wallpapers/`。没有壁纸时，主题用纯色或渐变背景。放法见 [assets/wallpapers/README.md](../assets/wallpapers/README.md)。

## 常见问题

- **页面提示连不上后端**：看后端窗口有没有报错。数据库路径不对时，连接指示灯会提示没找到数据库。
- **第一次打开很慢**：后端第一次加载数据库要十几秒，指示灯变绿后再操作。

## 目录结构

| 路径 | 内容 |
|---|---|
| `backend/` | 后端（FastAPI + SQLite）。`backend/app.py` 是入口，`backend/v2/` 是主体，`backend/clicker/` 是自动点击 |
| `web/` | 前端（React + Vite），开发说明见 [web/README.md](../web/README.md) |
| `tagnote/` | 导图引擎，前端和 Obsidian 插件共用 |
| `scripts/` | 启动调试版 Chrome 的脚本（自动点击用） |
| `examples/` | 样例：`maps/` 是样例导图，`classic-plans/` 是经典工作台的样例方案 |
| `data/` | 数据库和你自己的方案、清单、分档（不进 git） |

后端和前端都只监听 `127.0.0.1`，同一网络里的其他设备访问不到。
