# AI 设置

AI 是可选的。可以用三种方式之一：

- 你自己的 **API**（DeepSeek、通义千问、Kimi、OpenAI 等，也可以接本机的 Ollama）；
- 本机已登录的 **Claude Code**（`claude` 命令行）；
- 本机已登录的 **Codex**（`codex` 命令行）。

三种都没有时，工作台的「一句话填」和「问数据」页用不了，其他功能都不受影响。

## 能做什么

- **一句话填工作台**：在工作台的输入条里写想要的题库，例如「2024 年的百合番角色，别太冷门」，AI 把条件填进工作台。填完你可以接着改。
- **问数据**：在「问数据」页用一句话问数据库，例如「2024 年热度最高的 10 个动画角色」。AI 写一条查询，出题器在本机运行它；结果可以存成清单或工作台条件。

两处都有一个下拉框，用来选这次用哪种 AI：你设置的 API 服务商、「Claude（本机命令行）」、「Codex（本机命令行）」。默认用 API；API 没设置时，自动选第一个能用的。

## 用 API

1. 打开「设置 → AI」。
2. 在「服务商」里选一家，接口地址会自动填好。可选的有 DeepSeek、阿里云百炼（通义千问）、月之暗面 Kimi、智谱、硅基流动、OpenAI、Google Gemini、Anthropic、OpenRouter，以及在本机运行的 Ollama 和 LM Studio。都不是的话，选「自定义（OpenAI 兼容）」，自己填接口地址。
3. 填「模型」。模型名以服务商文档为准；选的不是 Anthropic 时，也可以点「列出模型」，再点一个填进去。
4. 填 API key。本机的 Ollama 和 LM Studio 一般不用填。
5. 点「测试」。看到「连上了」再点「保存」。

**API key 存在哪**

- 存在本机的 `backend/config.json` 里，明文保存。这个文件不进 git。网页上只显示「已保存（…后 4 位）」，读不到 key 本身。
- 不想把 key 写进文件，可以在启动后端前设置环境变量 `OUTSETTER_AI_API_KEY`。它优先于文件里的 key；这时网页上不能改 key。
- 换了接口地址（域名、端口或 http / https）又没有重新填 key 时，保存会清掉原来的 key，免得它被发到新地址。

## 用本机的 Claude Code 或 Codex

装好并登录 `claude` 或 `codex` 命令行后，重启后端，下拉框里对应的一项就能选。用的是你自己订阅的额度，不用在出题器里填 key。

- **只接受订阅登录**：Claude Code 要用 Claude 账号登录，Codex 要用 ChatGPT 账号登录。命令行是用 API key 登录的话，出题器会拒绝调用；想按量付费，用上面的「用 API」。
- **Claude 会预热**：选 Claude 时，出题器会在你点进输入框时提前启动一个 `claude` 进程，回答更快；空闲一段时间后自动关掉。
- **Codex 比较慢**，下拉框里标着「较慢」。

## 每次请求发送什么

用 API 时，请求发到你填的接口地址，按服务商的价格计费；用命令行时，由 `claude` / `codex` 发到它们各自的服务。内容是：

- 你输入的那句话；
- 一份说明，大约 6–7 千字：填工作台时是工作台的条件格式和填写规则，问数据时是数据库的表结构；
- 填工作台时，还有工作台当前的条件；
- 你的清单的名字和条数（标签清单还带前 40 个标签名），方便 AI 用上它们。

角色和作品数据都在本机，不会整份发出去。

## 其他

- **`max_tokens`**：网页上没有这一项。需要限制回复长度时，在 `backend/config.json` 的 `v2.ai.api.max_tokens` 里写一个整数。不写时，OpenAI 兼容接口不传这个参数，Anthropic 接口用 4096。
- **代理**：后端发 API 请求时会使用 `HTTPS_PROXY` / `HTTP_PROXY` 环境变量里的代理；本机地址（`127.0.0.1`、`localhost`）不走代理。
