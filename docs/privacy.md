# 联网和隐私

出题器只在本机运行，后端和前端都只监听 `127.0.0.1`。查数据、抽题、单人猜猜呗都不需要网络。

会访问外部网络的只有下面这些：

| 功能 | 默认 | 连到哪里 |
|---|---|---|
| 角色头像（「设置 → 显示角色头像」） | 关 | 向 `api.bgm.tv` 查头像地址，图片从 `lain.bgm.tv` 加载 |
| 导图里的作品封面（导图顶栏的「封面」） | 显示 | 从 `api.bgm.tv` 加载。选「隐藏」就不加载；Obsidian 插件里的导图也一样 |
| AI 辅助 | 没配置就不用 | 用 API 时，后端把提示词和你的问题发到你在「设置 → AI」里填的接口地址；用本机的 Claude Code / Codex 时，由它们发到各自的服务。详见 [ai.md](ai.md) |
| 单人猜猜呗的「搜 Bangumi 全库」（单人猜猜呗的设置里） | 关 | 后端把你输入的名字发到 `api.bgm.tv` 搜索；关着时只搜本地 |
| 点作品名 | — | 在浏览器里打开 `bgm.tv` 的条目页 |
| 自动点击 | 不用就不连 | 后端通过本机调试端口控制你自己启动的 Chrome，那个 Chrome 里的猜猜呗网页会联网；定位角色时后端会请求 `api.bgm.tv` |
| 安装和下载数据 | — | 装依赖的脚本从 PyPI 和 npm 下载；数据库从本仓库的 Releases 页面下载 |

另外，`tagnote/build.py` 生成的独立示例页打开时会从 Google Fonts 取字体。只有开发导图引擎时才会用到这个页面。
