# 经典工作台样例方案

253 个经典工作台的方案，用来试用经典工作台。经典工作台需要经典工作台数据，装法见 [docs/legacy.md](../../docs/legacy.md) 的「经典工作台」一节。

- 在方案库的「经典方案」标签页点「载入样例方案」，会把这些文件复制进 `data/plans/`；方案库里已有同名方案的不覆盖。
- 文件名就是方案名；`0101-1857` 这类名字是默认名（月日-时分）。
- 文件里的 `created_at` / `updated_at` 是固定值，不是方案的实际保存时间。
- 这些方案只能在经典工作台里用，不能载入「工作台」（它的方案格式不同）。
